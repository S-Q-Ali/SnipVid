# Build a Production-Ready Universal Video Toolkit

You are an expert full-stack engineer, UI/UX designer, DevOps engineer, FFmpeg specialist, and technical SEO engineer.

Build a **complete, production-quality web application** called **VideoToolkit**.

This must be a REAL working application, not a prototype, mockup, static frontend, or fake SaaS dashboard.

Do not create fake download buttons, fake progress bars, placeholder conversion results, or simulated processing.

Every major feature must be connected to a real backend implementation and tested.

---

# 1. PRODUCT GOAL

Build an all-in-one online video utility platform that allows users to:

1. Download publicly accessible videos from supported URLs/platforms.
2. Convert uploaded videos between common video formats.
3. Convert MPEG-4 files/videos to MP4.
4. Convert almost any supported input video to MP4.
5. Extract audio from videos.
6. Compress videos.
7. Resize videos.
8. Crop videos.
9. Trim videos.
10. Change FPS.
11. Change video/audio codecs.
12. Change bitrate and quality.
13. Convert videos for different social-media aspect ratios.
14. Process multiple files/jobs.
15. Download the final processed files.

The application should feel like a serious professional media utility rather than an "AI-generated website."

# 8. MPEG-4 TO MP4

This is a REQUIRED feature.

Create:

/mpeg-4-to-mp4

Also expose it through:

/video-converter

The application must correctly handle cases where:

1. MPEG-4 refers to a compatible codec inside another container.
2. MPEG-4 refers to a video file/container that needs remuxing or transcoding.

Processing strategy:

FIRST determine whether a simple container remux/stream-copy is possible.

If compatible:

* avoid unnecessary re-encoding
* preserve quality
* process quickly

If incompatible:

* transcode using FFmpeg
* use sensible H.264/AAC MP4 defaults

Do not blindly re-encode every file.

Use FFprobe to inspect:

* container
* video codec
* audio codec
* resolution
* FPS
* bitrate
* duration
* streams
